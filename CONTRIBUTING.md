# Contribuer

1. Créez une branche depuis la branche principale.
2. Installez l'environnement de développement avec
   `.venv\Scripts\python.exe -m pip install -e ".[dev]"`.
3. Ajoutez ou adaptez les tests avec chaque changement fonctionnel.
4. Exécutez `pytest`, `ruff check .` et `ruff format --check .`.
5. N'incluez jamais de configuration, URL, adresse, capture, journal ou donnée réelle.

Les rapports et serveurs utilisés dans les tests ou exemples doivent être entièrement
fictifs.
